## 五、推荐改稿顺序（C2 执行计划）

按"难易度 × 紧迫度 × 风险"排序：

### 阶段 1 · 易行精（ch11/12/13）
- **目标**：3 章 OVER 较轻，从 2400-2500 字 精到 1800-2200
- **操作**：删冗余环境描写 / 合并近似场景 / 删非必需铺垫
- **风险**：🟢 低（最近定稿，结构稳定）
- **预期耗时**：每章 30-45 分钟（机械性操作）

### 阶段 2 · 中等精（ch03/04/05/06/09/10）
- **目标**：6 章从 2400-2500 字 精到 1800-2200
- **操作**：同上 + 删重复动作 + 保留节奏钩子
- **风险**：🟡 中（中间章节，结构稳定但节奏密）
- **预期耗时**：每章 45-60 分钟

### 阶段 3 · 重症精（ch02/07/08）
- **目标**：3 章从 2500-2800 字 精到 1800-2200
- **操作**：同上 + 重点排查"铺垫 / 重复心理" / 保留开场钩子
- **风险**：🟠 中高（OVER 最严重，精简空间大）
- **预期耗时**：每章 60-90 分钟

### 阶段 4 · 极难扩（ch01）
- **目标**：1 章从 1293 字 扩到 1800-2200
- **操作**：在七号仓库场景新增"开篇钩子 350 → 调查推进 600"中某段落的细节 / 心理 / 环境
- **风险**：🔴 高（最难扩，且已有 v3 精炼稿，扩写可能破坏节奏）
- **预期耗时**：2-3 小时

**总预估耗时**：阶段1+2+3+4 = 约 8-10 小时人工改稿

## 六、**关键资源链接**

每章改稿时必读 `prompts/extract_ships_Chapter_NN.md` 看母题保留清单：

```
prompts/extract_ships_Chapter_01.md   ← ch01 母题（扩写时不要新增未登记母题）
prompts/extract_ships_Chapter_02.md   ← ch02 母题（精时可保留 / 删除冗余环境描写）
...
prompts/extract_ships_Chapter_13.md   ← ch13 母题（精时可保留 / 删除冗余心理）
```

改稿流程（每章）：
1. 读 `prompts/extract_ships_Chapter_NN.md` 锁定本章母题
2. 用 prose_lint 找具体病句位置（结合 err 数）
3. 删 / 补 / 改 字数到目标区间
4. 改完后立即跑：
   - `python engine/prose_lint.py chapters/Chapter_NN.md`（病句）
   - `python tools/punct_scan.py --chapters NN`（标点）
   - `python tools/cast_absence_scan.py --chapters NN`（角色）
   - `python engine/batch_rewrite.py status`（OVER/UNDER）
5. 三道门全过 → chapter 文件 OK
